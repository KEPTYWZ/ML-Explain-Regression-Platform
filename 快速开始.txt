===============================================
    机器学习回归分析平台 - 快速开始指南
===============================================

【平台简介】
    通用机器学习回归分析平台
    适用于各种数值型回归预测任务：
    - 混凝土材料性能预测
    - 结构承载力分析
    - 工程参数回归
    - 科研数据建模

【系统要求】
    Python版本：3.8 - 3.11（推荐3.11）
    ⚠️ 不支持Python 3.12+

【重要提示】
    ⚠️ numpy版本必须 < 2.0
    ⚠️ 如遇到版本冲突，请查看"使用说明.md"

===============================================

【第一步】安装依赖
    双击：install.bat
    等待安装完成（约2-5分钟）

【第二步】运行程序
    双击：run.bat
    浏览器会自动打开

【第三步】使用程序
    1. 上传CSV数据文件（任何回归数据）
    2. 选择目标变量
    3. 点击"开始训练"
    4. 查看结果

===============================================

【如果遇到numpy版本冲突】
    打开命令行，执行：
    pip install numpy==1.26.4 --force-reinstall
    pip install shap==0.42.0 --force-reinstall

【如果遇到其他问题】
    1. 确保已安装Python 3.8-3.11
    2. 查看"使用说明.md"文件
    3. 使用命令行运行：
       pip install -r requirements.txt
       streamlit run app.py

【访问地址】
    http://localhost:8501

【停止程序】
    在命令行窗口按 Ctrl+C
