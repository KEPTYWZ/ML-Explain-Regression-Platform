# 🤖 机器学习回归分析平台

一个功能完整的**通用机器学习回归分析平台**，基于Streamlit构建，提供从数据导入到模型部署的完整工作流程。

**适用场景：**
- 🏗️ 混凝土抗压强度预测
- 🔩 锈蚀预应力混凝土承载力分析
- 🏭 材料性能预测
- 📊 工程参数回归分析
- 🔬 科研数据建模
- 📈 任何数值型回归预测任务

## 📋 系统要求

### Python版本
- **推荐：Python 3.11**
- 支持：Python 3.8 - 3.11
- ⚠️ 不支持：Python 3.12+（部分依赖包尚未兼容）

### 关键依赖版本
- **numpy < 2.0**（必须！numpy 2.x会导致兼容性问题）
- **shap 0.42-0.44**（兼容numpy 1.x）

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Windows系统（推荐使用conda环境）

### 安装步骤

1. **创建虚拟环境（推荐）**
```bash
conda create -n env6 python=3.8
conda activate env6
```

2. **安装依赖**
```bash
# 运行安装脚本
install.bat

# 或手动安装
pip install -r requirements.txt
```

3. **启动应用**
```bash
# 使用启动脚本
run.bat

# 或使用conda环境启动
run_env6.bat

# 或手动启动
streamlit run app.py
```

4. **访问应用**
浏览器自动打开 `http://localhost:8501`

## ⚠️ 注意事项

1. **数据格式**
   - 确保数据为数值型
   - 目标变量应为连续值（回归任务）
   - 避免包含过多缺失值

2. **模型选择**
   - 小数据集（<1000样本）：随机森林、SVR
   - 中等数据集（1000-10000样本）：随机森林、LightGBM
   - 大数据集（>10000样本）：LightGBM、XGBoost

3. **超参数优化**
   - 贝叶斯优化需要较长时间
   - 建议先使用默认参数快速测试
   - 确定模型后再进行优化

4. **符号回归**
   - 计算密集，建议特征数<10
   - 增加种群大小和代数可提高精度
   - 但会显著增加计算时间

5. **SHAP分析**
   - 大数据集建议减少样本数
   - 树模型计算较快
   - 神经网络计算较慢

## 🐛 常见问题

### 1. 启动失败
- 检查Python版本（需要3.8+）
- 确认所有依赖已安装
- 尝试重新安装：`pip install -r requirements.txt --force-reinstall`

### 2. 模型训练错误
- 检查数据是否包含缺失值
- 确认特征和目标变量选择正确
- 查看错误信息，可能是参数设置问题

### 3. SHAP分析失败
- 确认已安装shap包：`pip install shap`
- 减少样本数
- 某些模型可能不支持SHAP

### 4. 符号回归失败
- 确认已安装gplearn包：`pip install gplearn`
- 减少特征数量
- 降低种群大小或代数

### 5. 可视化显示问题
- 中文标签显示为方框：安装中文字体
- 图表过宽：已自动调整，如仍有问题请参考手动修复指南
